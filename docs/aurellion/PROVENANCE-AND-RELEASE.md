## Preserve-original protocol

- Original exports, files, and repository histories are read-only sources.
- Use work copies for transformations.
- Record a content hash for each captured artifact.
- Keep raw-file SHA-256, Git blob SHA, commit SHA, UUID, and transaction hash in separate fields.
- Record transformations as new artifacts with source references.
- Missing source metadata remains missing; do not infer a title, timestamp, author, or hash.

## Evidence vocabulary

- `DOCUMENTED` — described in an artifact.
- `IMPLEMENTED` — code or content exists at a specified path and commit.
- `TESTED` — a named test was executed and its result recorded.
- `VERIFIED` — a named reviewer checked a defined claim.
- `STAGED` — deployed to a named non-production environment.
- `DEPLOYED` — deployed to a named environment with release evidence.
- `ACTIVE` — currently operating, with current health evidence.

Do not use one state as a substitute for another.
